# C4 Explosives Mod

A Fabric mod for Minecraft 1.20.1 that adds C4 explosives with remote detonation, increased range, and power. This mod introduces two types of C4 explosives: standard C4 blocks and portable C4 items. The standard C4 blocks can be placed in the world and detonated remotely using a detonator. The portable C4 items can be thrown and attached to mobs, causing them to explode when detonated.

## Install

1. Install Fabric Loader for Minecraft 1.
